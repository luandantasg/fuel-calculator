## Sobre o projeto

Esse é um projeto android que utiliza a linguagem Kotlin para fazer o calculo de combustível da sua viagem!

## Tecnologías utilizadas
Nesse projeto utilizamos as tecnologías abaixo onde o usuário consegue ter o resultado de um calculo de combustível de uma maneira mais intuitiva
- Activity
- ConstraitLayout
- ImageView
- View
- Kotlin
- ConstraintLayout
- UI components
- TextImputLayout
- TextView
- EditText
- Button
- Intent to open Activity´s
- SetOnClickListener
